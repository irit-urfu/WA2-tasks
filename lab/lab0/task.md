# ДЗ 0. Техническое задание на Boardy

> **Срок:** 07.10.2026, 14:00 (Екатеринбург) · **Сдача:** Pull request `lab0` → `main`, в описании `Closes #<номер задачи>`

## Цель
Восстановить техническое задание на доставшуюся систему: что она делает и что должна делать. Это первая часть ТЗ — функциональные требования. Нефункциональные пока не пишем.

## Перед началом
- Получите репозиторий: https://ai-info.ru/?c=wa2 → войдите через GitHub → выберите себя → примите приглашение.
- Установлены Git и Docker.
- `git clone <ваш репозиторий>` → `git checkout -b lab0`

## Как выполнять
1. **Запустите проект:** `docker compose up -d`. *Проверка:* http://localhost:8080 открывает ленту, http://localhost:8080/api/docs — документацию API. Если что-то мешает запуску — исправьте только это.
2. **Пройдите систему руками** и составьте список функций: лента, объявление, комментарии, регистрация, вход, подача объявления, пользователи, API. *Проверка:* каждую функцию вы сами выполнили.
3. **Опишите назначение системы:** что она делает, для кого, какие роли пользователей.
4. **Напишите ТЗ — функциональные требования:** пользовательские истории («Как *роль*, я хочу *действие*, чтобы *цель*») и к каждой пронумерованные ФТ (ФТ-1.1, ФТ-1.2…). У каждого ФТ — вход, что делает система, результат, реакция на ошибку. *Проверка:* каждая функция из шага 2 покрыта хотя бы одним ФТ.

3. Сдано в срок, если запрос открыт до срока — время фиксирует GitHub.
