# ДЗ 1. Исправление Boardy

> **Срок:** 07.10.2026, 14:00 (Екатеринбург) · **Сдача:** Pull request `lab1` → `main`, в описании `Closes #<номер задачи>`

## Цель
Привести систему в рабочее состояние: исправить косяки, которые вы нашли и которые ещё не нашли, и довести функциональные требования.

## Перед началом
- ДЗ 0 сдано (запрос на слияние `lab0` принят или открыт).
- `git checkout main && git pull` → `git checkout -b lab1`

## Как выполнять
1. **Составьте список исправлений** по общему документу с пары 30.09. Допишите косяки, которые найдёте по ходу.
2. **Исправляйте по одному:** одно исправление — один коммит, в сообщении — что было не так и чем грозило. *Проверка:* после каждого исправления `docker compose up -d` поднимается, функции работают.
3. **Обязательно** — технические дефекты, которые влияют на работу всей системы. Логирование, алерты и метрики на этом этапе не требуются.
4. **Доведите функциональные требования** из ДЗ 0, если не успели.
5. **Запишите итог** в отчёт: что исправлено (со ссылками на коммиты), что осталось и почему.

## Что сдать
| Что | Где в репозитории |
|---|---|
| Исправления | в коде, по коммиту на исправление |
| Итог: исправлено / осталось | `lab/lab1/report.md` |
| Функциональные требования (финал) | `lab/lab0/report.md` |

## Критерии приёмки
| # | Критерий | Баллы |
|---|---|---|
| 1 | Система поднимается с чистого клона и все функции работают | 20 |
| 2 | Исправлены технические дефекты, влияющие на всю систему | 40 |
| 3 | Каждое исправление — отдельный коммит с понятным сообщением | 15 |
| 4 | Отчёт: исправлено (ссылки на коммиты) / осталось и почему | 15 |
| 5 | Функциональные требования доведены | 10 |
| | **Итого** | **100** |

**Не принимается:** система не поднимается; все правки одним коммитом; работа сделана нейросетью.

## Как сдать
1. `git push -u origin lab1`
2. На GitHub: **Pull request** `lab1` → `main`, в описании `Closes #<номер задачи>`.
3. Сдано в срок, если запрос открыт до срока — время фиксирует GitHub.
