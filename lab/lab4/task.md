# ДЗ 4. Журналы всех сервисов Boardy — в папке ./logs

> **Срок:** 28.10.2026, 14:00 (Екатеринбург) · **Сдача:** Pull request `lab4` → `main`, в описании `Closes #<номер задачи>`

## Цель
Довести до конца решение с практики 21.10: каждый сервис Boardy сам пишет свои журналы в папку проекта `./logs/<сервис>`, у каждой папки правильный владелец. Это закрывает строку чек-листа НФТ «журнал есть у каждого сервиса и известно, где он» (сопровождаемость · анализируемость).

## Перед началом
- Boardy поднимается: `docker compose up -d` → http://localhost:8080.
- `git checkout main && git pull` → `git checkout -b lab4`. Если на практике вы уже начали в другой ветке — продолжайте в ней и назовите PR `lab4`.
- Пошаговые фрагменты конфигов — в методичке `lab/lab4/guide.md`.

## Как выполнять
1. **Карта «было».** Для каждого сервиса — nginx, php-fpm, Laravel, FastAPI (uvicorn), MySQL, Redis — запишите, какие журналы он пишет и куда. *Проверка:* таблица в `lab/lab4/report.md`.
2. **Папки и права.** Создайте `./logs/<сервис>` для всех шести сервисов и отдайте каждую тому пользователю, под которым сервис пишет журнал. *Проверка:* после `docker compose up -d` с чистой папки `logs/` все сервисы пишут журналы без ошибок прав; `logs/` в `.gitignore`.
3. **nginx, Laravel, uvicorn** — то, что начали на практике, доведите до рабочего состояния у себя. *Проверка:* после открытия ленты и запроса к API строки появились в `logs/nginx/access.log`, `logs/laravel/…`, `logs/api/…`.
4. **php-fpm.** Журнал ошибок и журнал доступа — в `logs/php-fpm/`. *Проверка:* `php-fpm -tt` показывает ваши пути; после открытия ленты в `logs/php-fpm/` есть журналы.
5. **MySQL.** Журнал ошибок — в `logs/mysql/`. *Проверка:* после перезапуска MySQL в журнале строки запуска.
6. **Redis.** Журнал — в `logs/redis/`. *Проверка:* после перезапуска Redis в журнале строки запуска.
7. **Карта «стало».** *Проверка:* в отчёте таблица «сервис → журнал → путь в контейнере → файл на хосте → владелец».

## Что сдать
| Что | Где в репозитории |
|---|---|
| Журналы всех сервисов, права | `docker-compose.yml`, конфиги сервисов (`infra/…` или в каталогах сервисов) |
| Карты «было / стало», проверки | `lab/lab4/report.md` |

## Критерии приёмки
| # | Критерий | Баллы |
|---|---|---|
| 1 | Журналы всех шести сервисов пишутся в `./logs/<сервис>` и появляются после запуска с чистой папки | 50 |
| 2 | Права: каждая папка у своего владельца, без `chmod 777` | 20 |
| 3 | Отчёт: карты «было / стало», проверки | 30 |
| | **Итого** | **100** |

**Не принимается:** журналы в репозитории (папка `logs/` не в `.gitignore`); `chmod 777` на папки журналов; система не поднимается с чистого клона; работа сделана нейросетью.
