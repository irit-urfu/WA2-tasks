**Преподаватель:** Шадрин Денис Борисович · ИРИТ-РТФ УрФУ · 2026/27, осенний семестр

## О курсе
Берём работающий веб-сервис Boardy (доска объявлений) и неделя за неделей доводим его до системы, которая выдерживает нагрузку, переживает сбои и доказывает это замерами. К концу семестра в этом репозитории — ваша промышленная версия Boardy и записи о принятых решениях.

## Начало работы
1. Репозиторий получен на https://ai-info.ru/?c=wa2 (личный, приватный).
2. `git clone <ваш репозиторий>` и `cd` в него.
3. Нужны Git и Docker. Запуск: `docker compose up -d` → http://localhost:8080 (лента), http://localhost:8080/api/docs (API).
4. Проверка: `docker compose ps` — пять сервисов работают.

## Структура репозитория
| Путь | Что там |
|---|---|
| `docker-compose.yml` | все сервисы системы |
| `infra/nginx/` | входной веб-сервер |
| `services/php/` | Laravel: страницы, вход, объявления |
| `services/api/` | FastAPI: REST и уведомления |
| `lab/labN/task.md` | задание N |
| `lab/labN/report.md` | ваш отчёт по заданию N |
